# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by emailing [shekhar.rj@gmail.com](mailto:shekhar.rj@gmail.com).

Please include:
- A description of the vulnerability
- Steps to reproduce it
- Any potential impact

I will respond within 48 hours and aim to issue a fix within 7 days for confirmed vulnerabilities.

Do not open a public GitHub issue for security vulnerabilities.
